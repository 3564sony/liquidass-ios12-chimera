# 0.1.1-2b+ios12

Experimental iOS 12.0–12.5.x rootful Chimera/Sileo compatibility package.

- Legacy `iphoneos-arm` package layout.
- Firmware dependency changed to `>= 12.0, < 13.0`.
- Mach-O minimum OS metadata changed from 14.0 to 12.0.
- Binaries ad-hoc signed for jailbreak loading.
- Newer iOS 15/16 process targets removed from the package build configuration.
